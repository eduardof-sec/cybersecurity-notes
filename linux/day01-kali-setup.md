# Day 01 — Kali Linux Setup and First Terminal Commands

Today I started using Kali Linux inside a virtual machine and practiced basic Linux terminal commands.

## Commands I used and what they do

### pwd
Shows the current directory I am in.

### ls
Lists files and folders in the current directory.

### whoami
Displays the current user running the terminal.

### uname -a
Shows system information such as kernel version and architecture.

### ip a
Displays network interfaces and my IP address.

## Filesystem practice

I created and manipulated files and folders using:

- mkdir → create folders
- cd → navigate between directories
- touch → create empty files
- cp → copy files
- mv → move/rename files
- rm → delete files

This helped me understand how the Linux filesystem works.

## Permissions

I used:

chmod 777 arquivo1.txt

and observed permission changes with:

ls -l

This showed me how file permissions work in Linux.

## Processes

I used:

top

to monitor running processes in real time.

## What I learned

Today I learned how to navigate through the Linux terminal, manage files and folders, check system and network information, and understand basic permissions and processes.
